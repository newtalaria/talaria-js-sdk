# Next.js example (copy-paste)

These files are the canonical Next 15 App Router wiring for `@newtalaria/nextjs`. Copy them into a Next app; they are not a standalone install.

1. `npm install @newtalaria/nextjs`
2. Copy the files next to your `app/` directory
3. Set `NEXT_PUBLIC_TALARIA_*` (client) and `TALARIA_*` (server) env vars
4. Visit `/`, click the client button, hit `/api/boom`, and submit the server action
